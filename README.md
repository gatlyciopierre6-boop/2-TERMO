## 🟢 Backend

Os exercícios de Backend estão organizados dentro da pasta `BACKEND/`.

### Pré-requisitos

Para executar os exercícios de Node.js, é necessário ter uma versão LTS do Node.js instalada.

Após instalar o Node.js, entre na pasta do Backend:

```bash
cd BACKEND
```

Instale as dependências:

```bash
npm install
```

### Executando os exercícios

Os principais scripts disponíveis são:

```bash
npm run vendas
npm run imc
npm run atividade-final
```

### Testes

O comando abaixo verifica a sintaxe dos arquivos JavaScript do Backend:

```bash
npm test
```

O teste não executa entradas interativas. Ele serve para verificar possíveis erros de sintaxe nos arquivos JavaScript.

## 🗄️ Banco de Dados

Os exercícios de Banco de Dados estão organizados dentro da pasta:

```text
BANCO DE DADOS/
```

O projeto SmartCoffee possui três etapas de modelagem:

```text
SMARTCOFFEE_CONCEITUAL.brM
SMARTCOFFEE_LOGICO_1.brM
SMARTCOFFEE_FISICO.sql
```

### Modelo conceitual

O arquivo:

```text
SMARTCOFFEE_CONCEITUAL.brM
```

representa o modelo conceitual do banco de dados.

### Modelo lógico

O arquivo:

```text
SMARTCOFFEE_LOGICO_1.brM
```

representa a estrutura lógica do banco de dados.

### Modelo físico

O arquivo:

```text
SMARTCOFFEE_FISICO.sql
```

contém o script SQL utilizado para criar a estrutura física do banco.

O script foi organizado para utilização com MySQL 8.0 ou superior.

### Importando o banco

Com o MySQL instalado e um banco criado, o script pode ser importado utilizando:

```bash
mysql -u seu_usuario -p seu_banco < "BANCO DE DADOS/AULA2/SMARTCOFFEE_FISICO.sql"
```

Os arquivos `.brM` podem ser utilizados para continuar a edição dos modelos no brModelo.
