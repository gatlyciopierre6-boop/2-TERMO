## 🛠️ Grade Tecnológica

*   **🌐 LIMA (/LIMA):** HTML5 e CSS3 para páginas responsivas.
*   **💻 Back-end (/BACKEND):** JavaScript (ES6+) e Node.js para lógica e scripts.
*   **🗄️ Banco de Dados (/BANCO DE DADOS):** MySQL 8.0+ e modelagem com brModelo.

## 📁 Estrutura do Repositório
```text
2-TERMO/
```

## 🚀 Guia de Execução

1.  **Back-end:** `cd BACKEND && npm install` (necessário Node.js instalado).
2.  **Front-end:** Abra `index.html` via Live Server ou `python3 -m http.server`.
3.  **Banco de Dados:** Importe os arquivos `.sql` no MySQL.
